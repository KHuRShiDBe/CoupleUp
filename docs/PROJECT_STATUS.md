## 3. Реализованные функции

Навигация: нижние вкладки «Главная», «Чат», «Настройки» + экраны стека.

- **Онбординг:** выбор языка (ru / en / uz), роль (парень / девушка — задаёт синюю или бордовую тему), имя, подключение партнёра по коду. Работает и без Supabase (локальный режим).
- **Аккаунт:** анонимный вход, привязка email, выход из пары, блокировка пользователей, жалобы, удаление аккаунта (Edge Function `delete-account`), экспорт своих данных в JSON, центр приватности.
- **Баллы и BOND:** журнал действий, курс BOND, личный кошелёк, история операций, финансы.
- **Подтверждение партнёром:** действия, квесты и бонусы отправляются партнёру на подтверждение (`action_requests`).
- **Задания, награды, штрафы, запросы, общие цели, достижения.**
- **Ежедневное:** ежедневные действия, бонус дня, колесо дневной награды, календарь, дайджесты (день / неделя).
- **Квесты:** дневные / недельные / месячные / годовые пулы, замена пунктов, бонусы.
- **Рулетки:**
  - Рулетка желаний — 20 секторов с номерами 1–20, кнопка 📖 со списком призов, номер выпавшего сектора в результате; призы сохраняются в инвентарь.
  - Магазинная рулетка, интимная рулетка (только при согласии обоих, купоны), рулетка пары, хаб рулеток.
- **Инвентарь / выигрыши** (`wish_inventory`).
- **Чат пары** со значками непрочитанного.
- **Уведомления:** список в приложении через Supabase Realtime; push через Edge Function `send-push`; напоминания; «пнуть партнёра».
- **Пара:** настроение (check-in и история), комплименты, моменты, важные даты, вопрос дня, статистика, сводки.
- **Планирование:** привычки, обещания, идеи свиданий, желания, сюрпризы, план-доска, календарь.
- **Деньги:** бюджет, расходы, честное разделение, накопления, список покупок, запросы на покупку со встречными предложениями.
- **Игры:** квиз о партнёре, правда или действие, «это или то», квиз пары, сундук наград, недельные челленджи, колесо свиданий.
- **Магазин тем и украшений** (покупки — демонстрация, реальных платежей нет).
- **Устойчивость:** Error Boundary с экраном восстановления; защита экранов от неверных параметров.

## 5. Известные ошибки и незавершённые задачи

**Ограничения среды:**

- Expo Go на Android: системные push и локальные напоминания отключены (в Expo Go нет нужного нативного модуля). Для push нужна dev-сборка (`expo-dev-client` + EAS) — не делалось.
- Нет `extra.eas.projectId` в `app.json`, поэтому push-токен не регистрируется.

**Не проверено на телефоне / с сервером:** вход, создание пары, синхронизация, вращения рулеток (включая номер сектора), push, удаление аккаунта.

**Открытые задачи:**

1. Текст политики конфиденциальности в приложении устарел (утверждает, что данные хранятся только локально). Черновик готов, нужны ответы владельца.
2. Бакет `profile-photos` публичный; `delete-account` не удаляет файл фото из Storage.
3. Миграция `0044` — перенести в основную ветку или отказаться (решение владельца).
4. `supabase/README.md` описывает только миграции `0001`–`0004`.
5. Иконки и фон: обновлённые PNG (`male/home1.png`, `*/settings-transparent.png`) и обои (`bg-male12.png`, `bg-female1.png`) лежат в `assets`, но не подключены; фон экранов сейчас белый. Задача «кнопка настроек + общий фон» не выполнена.
6. Очистка: около 64 неиспользуемых PNG (~40 МБ) и 6 неимпортируемых TS-файлов — ждёт разрешения.
7. `npm audit`: уязвимости в транзитивных зависимостях инструментов сборки (не в коде приложения).
8. Предупреждения стилей (`shadow*` → `boxShadow`), нет линтера и тестов, имя шаблона `CoupleUp_scaffold` в `app.json`.

## 6. Запуск (Windows CMD + Expo Go)

Первый раз:

```cmd
cd /d %USERPROFILE%\Desktop
git clone -b claude/awesome-ramanujan-2tmxw4 https://github.com/KHuRShiDBe/CoupleUp.git CoupleUp-sdk58
cd CoupleUp-sdk58
copy .env.example .env
```

Заполнить в `.env` значения `EXPO_PUBLIC_SUPABASE_URL` и `EXPO_PUBLIC_SUPABASE_ANON_KEY` (только anon-ключ, никогда service_role). `.env` в Git не хранится.

Запуск:

```cmd
cd /d %USERPROFILE%\Desktop\CoupleUp-sdk58
git pull
node -v
npm ci
npx expo start --clear
```

- Отсканировать QR в Expo Go SDK 58 (Android — из Expo Go, iPhone — камерой).
- Телефон в другой сети: `npx expo start --clear --tunnel`.
- Проверка типов: `npm run typecheck`.

Признаки нужной версии: в «Рулетке желаний» номера 1–20 и кнопка 📖; есть вкладка «Чат».

## 7. Правила разработки

- Работаем **только** в ветке `claude/awesome-ramanujan-2tmxw4`.
- Меняем только необходимые файлы; без полного аудита без необходимости.
- Экономим токены.
- Не удаляем рабочие функции.
- **SQL, миграции, RLS и Supabase — только с разрешения владельца.**
- Не делаем merge в `master`.
- Не удаляем ветки и резервные копии без разрешения; без force push.
- Commit / push — только по явной просьбе владельца (не по автоматическим напоминаниям).
- Не добавляем секреты (`.env`, ключи) в Git.
- Перед изменениями сверяемся с документацией Expo SDK 58: https://docs.expo.dev/versions/v58.0.0/ (в `AGENTS.md` пока ссылка на v57).
- После изменений: `npx tsc --noEmit`.
